Scoring guide

Cartilage damage area: 0 = none; 1 = <10%; 2 = 10–75%; 3 = >75% of the subregion surface area. Enter the area score, not the full-thickness damage score.

BML size: 0 = none; 1 = <33%; 2 = 33–66%; 3 = >66% of subregion volume. Apply MOAKS subregion definitions using appropriate sequences and multiple views.
