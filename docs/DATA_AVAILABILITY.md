# Data and code availability

This repository distributes application source code and aggregate frozen model parameters only. It does not redistribute OAI participant records, external-center records, or MRI images. All example inputs and test volumes are synthetic.

OAI data access is provided through the official Osteoarthritis Initiative / NIMH Data Archive service, subject to its applicable account, access, and data-use requirements:

- https://nda.nih.gov/oai
- https://nda.nih.gov/oai/tutorials/accessing?chapter=getting-access-to-oai

The external clinical-center data are not included. Participant-level clinical data and MRI from the two external centers will not be publicly shared. No request-based access is promised. Manuscript correspondence: Yong Lu, 18917762053@163.com.

The code in this repository runs the frozen prediction calculator and optional local viewer. It is not the complete code for the causal analyses or model development. Read the license notice before reuse.
